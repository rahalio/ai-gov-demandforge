# Demandforge — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Enterprise AI / operations leader

- As an operations leader, I want to publish a problem brief with success metrics, so that suppliers respond to my pain rather than pitch generic models.
- As an enterprise buyer, I want comparable in-sector value proofs, so that I can select suppliers despite low familiarity.
- As a risk owner, I want decision-liability and explanation checks before scale, so that we do not automate our way into an unowned decision.

### Startup / AI supplier

- As a startup BD lead, I want matched problem flow from Canadian buyers, so that we can refine applications domestically before exporting.
- As a supplier, I want a standard value-proof template, so that proving business value is not reinvented per pilot.
- As a founder, I want commercialisation-readiness feedback, so that we know whether our gap is product or go-to-market talent.

### Institute / talent officer

- As a talent officer, I want placements tied to live problem engagements, so that researchers see advanced problems without leaving Canada.
- As an institute lead, I want aggregated demand signals by city node, so that we can align training to real buyer needs.

### Policymaker / programme funder

- As a programme funder, I want drawdowns gated on value proofs, so that public money does not subsidise perpetual pilots.
- As a policymaker, I want barrier dashboards (trust, skills, data, discovery), so that policy instruments target measured gaps.
- As a workforce official, I want reskilling demand signals from adopting firms, so that training programmes match disruption where it actually appears.

### Platform administrator / compliance

- As a compliance officer, I want competitive problem briefs compartmentalised, so that rival firms cannot see each other’s pipelines.
- As a platform administrator, I want explicit IP and data-residency terms on each engagement, so that open-economy defaults are chosen rather than assumed.
- As a trust officer, I want citizen-facing summaries of safeguard coverage, so that the preparedness gap (1 in 10) has a visible improvement path.
